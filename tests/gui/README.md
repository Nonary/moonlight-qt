Run the VRR settings input regression from the repository root with Qt's
`qmltestrunner` on PATH:

```powershell
qmltestrunner -input tests/gui -import tests/gui/imports -platform offscreen -o build/qml-input-test.txt,txt
if ($LASTEXITCODE -ne 0) { throw "VRR input regression failed" }
Get-Content build/qml-input-test.txt
```

The test uses the real VRR settings component with an isolated navigation
singleton. Left/right key events match those generated by the controller bridge.
No saved user preferences or physical controller are required.
